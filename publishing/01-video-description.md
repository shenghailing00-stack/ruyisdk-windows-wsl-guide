## 标题

【RuyiSDK 新手教程 01】Windows 安装 WSL 2 与 Ubuntu 24.04

## 简介

本期介绍 Windows 下 RuyiSDK 开发环境的第一步：准备 WSL 2 并安装 Ubuntu 24.04。

主要内容：

- 检查电脑是否已经安装 WSL；
- 单独安装 WSL，并设置默认使用 WSL 2；
- 查看并安装 Ubuntu 24.04；
- 完成 Ubuntu 首次启动和用户创建；
- 验证 Ubuntu 版本、WSL 版本、内核和处理器架构；
- 分清 PowerShell 与 Ubuntu 终端；
- 创建后续教程使用的 Linux 工作目录。

配套仓库：https://github.com/shenghailing00-stack/ruyisdk-windows-wsl-guide

完整图文：https://github.com/shenghailing00-stack/ruyisdk-windows-wsl-guide/blob/master/docs/01-install-wsl2.md

下一期将初始化 Ubuntu，检查软件源和网络，并安装后续操作需要的基础工具。
