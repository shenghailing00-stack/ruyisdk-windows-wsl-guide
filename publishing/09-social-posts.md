## B 站动态

模拟器跑通之后，最后把同一个程序放到真实开发板上验证。本期从 SSH 登录、架构确认和板端目录开始，演示 SCP 上传、真实 RISC-V 运行与文件取回，也说明为什么 VS Code Remote - SSH 目前不能作为所有 RISC-V 板卡的通用方案。

不同开发板的用户名、IP、镜像和 SSH 开启方式不同，请以对应板卡的官方文档为准。

配套教程：https://github.com/shenghailing00-stack/ruyisdk-windows-wsl-guide/blob/master/docs/09-connect-board-ssh.md
