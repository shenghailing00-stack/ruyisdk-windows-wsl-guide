## 可直接使用的口播

“这台测试机之前已经安装过 WSL，所以本期不会把既有环境包装成一次新的
安装。对于新电脑，核心安装命令是 `wsl --install -d Ubuntu-24.04`；安装
完成后，无论是新环境还是既有环境，都要回到同一套验收：确认发行版的
VERSION 为 2，再确认 Ubuntu 版本、Linux 内核和处理器架构。”

“这里还能看到 localhost 代理没有镜像到 NAT 模式 WSL 的警告。它不影响
我们确认 WSL 2 和 Ubuntu 正常启动，但可能影响后续下载。下一节会先做
DNS 和 HTTPS 实测，再决定是否需要改网络配置。”
