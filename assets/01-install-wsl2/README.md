# 第 01 节截图清单

只提交经过检查的发布截图；原始截图放在 `raw/`，该目录已被 `.gitignore`
排除。

| 文件名 | 必须包含 | 必须隐藏 |
|---|---|---|
| `01-winver.png` | Windows 版本与 Build | 注册用户、产品 ID（如出现） |
| `02-wsl-ubuntu-environment.png` | WSL 版本、`VERSION=2`、Ubuntu 版本、内核与架构 | Windows/Linux 用户名、计算机名 |

如果是在全新 Windows 上真实执行安装，可额外保留 `03-wsl-install.png`。
如果测试机在录制前已经安装 WSL，不得补造安装成功截图；正文应明确标注为
“既有环境验证”，安装步骤引用官方命令和文档。

## 建议尺寸

- 正文截图：宽度至少 1400 px，PNG。
- 视频画面：1920×1080。
- 保留必要上下文，不截成只有一行、无法判断命令来源的碎片。

## 截图后检查

- [x] 没有用户名、计算机名、IP、Token、代理地址。
- [x] 没有微信、邮箱或其他弹窗通知。
- [x] 命令与输出属于同一次真实操作。
- [x] 图片没有用 AI 生成或修改技术输出；仅进行了截图裁剪。
